# Upgrade: generated agent files and Cursor command links

Applies when you bump `@zedtech/zedkit-ai` to the minor that adds
`zedkit-ai sync` and routes models through `.agents/tokenomics.md`. Skills,
the shared `.agents/` source and your own files do not change.

## What changes

| Path | Before | After |
|---|---|---|
| `.cursor/agents/*.md` | copy of the source | generated, `model` from the policy, marker on line 2 |
| `.claude/agents` | link to `.agents/agents` | real directory of generated files |
| `.cursor/commands/*.md` | copy of the source | link to `.agents/commands/<name>.md` |
| `validate` drift | "differs from", "copy missing" | "stale copy of the kit", "out of date", "missing", each ending `run: npx @zedtech/zedkit-ai sync` |

Every generated agent file starts with `---`, then
`# generated by zedkit-ai sync ...; do not edit`. Edit the source or the
policy and run `npx @zedtech/zedkit-ai sync`; a hand edit is overwritten.

## Steps

1. Bump the package, then run `npx @zedtech/zedkit-ai sync` (or `npx @zedtech/zedkit-ai init --adopt`, which now calls it).
2. Read the output. Lines that start `generate`, `link`, `convert` and `prune` are changes; `skip` lines say what was kept and why.
3. Commit the result. `npx @zedtech/zedkit-ai sync --check` exits 1 when a file is out of date, for CI.

## What is replaced and what is kept

- A file with the marker is regenerated.
- A file that is byte for byte a copy of a kit file (the current text or any version a past release installed) is replaced.
- Anything else is yours and stays. The generated version goes beside it as `<name>.kit.md`, and `validate` says `user file kept` until it is there.
- A `.claude/agents` link made by `init` becomes a real directory. Any other link, and any provider folder that is itself a link (`.cursor -> .agents`), is left alone.
- A generated file whose source agent is gone is removed unless you pass `--no-prune`. Only files with the marker are ever removed.

## Behavior changes to expect

- `init --adopt` over a user file in `.cursor/commands` now writes `<name>.kit.md` as a link to the source; before, it was a copy.
- An agent source that cannot be generated from (no frontmatter) is skipped with a `not synced` note by `init` and `validate`; `sync` stops and names it.
- Models stay `inherit` until `tokenomics.md` names one. Check an id against your tool's model list first: an unknown id falls back to the session model without an error.
