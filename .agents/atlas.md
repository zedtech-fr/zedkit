# Atlas

Where things live, what we call them, how to run them, why we chose them. Before a task, read the row for your topic, open its Entry, and widen the search only if it does not hold. Rows are leads, not law.

- **Add a row** the same turn a search cost 3 or more reads, or a correction was about a path, a word or a command. One row, one line.
- **Fix in place.** Never append a duplicate; replace a stale fact. A row one search away does not belong here: delete it. A moved file or changed command fixes its row in the same change.
- **Link, never copy.** The rule, ADR or domain file owns the why; the row names it. No secrets, no private names.
- **Bounded.** About 120 lines. `zedkit-ai validate` fails past 150 lines, and on any path in the Entry column of Where that no longer exists.
- A read-only task (audit, review, subagent) writes nothing: it lists rows to add, fix or drop under `Atlas:` in its report; the caller writes them. Stale factual rows are deleted without asking; changing a rule is a separate step.

## Reference durability

Durable references name `path#symbol/section#excerpt` plus the commit they were verified against; bare lines are accepted only with that commit. Quiet line movement resolves through the symbol's own body or section; a missing, changed, or ambiguous association is reported explicitly, never silently passed and never broadened to unchanged content. Enforced for atlas rows by `checkAtlas` (`packages/ai/src/atlas.ts#checkAtlas#stale row`, wired into `validate` via `packages/ai/src/cli.ts#runValidate#checkAtlas`; verified against `1d8da98`); domain and design tables follow the same shape by convention, fixed progressively — no bulk migration, no index engine.

| Decision                           | Reason                                                                                                                             | Source                             |

| No fast model id anywhere          | A spawn that falls to a fast default hides which model reviewed; the cell is passed as is, never substituted                       | A-08 in `.agents/domain/ai-kit.md` |
| The cheapest cells never decide    | Synthesis and verdicts stay on `sensitive` cells or above; every spawn takes the cell of its kind × stakes, never the parent model | `.agents/tokenomics.md`            |
| Kit text carries no repo specifics | The kit ships to other repos; this repo's paths and traps live in `AGENTS.md` and here                                             | `packages/ai/AGENTS.md`            |
