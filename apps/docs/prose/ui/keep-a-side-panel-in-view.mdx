## Who this is for

You ship docs, onboarding, or pricing pages where one column scrolls (steps, form fields) and a short preview or summary should stay visible until the reader leaves the section.

## Prerequisites

- React 19 and `@zedtech/zedkit-ui` styles imported (see [Theme an admin app](/docs/ui/theme-an-admin-app-dark-light-included)).
- A fixed or sticky site header — set `--zk-sticky-top` on the layout root if the default `--zk-pin-top` is too short.

## Steps

### 1. Wrap main and aside

Put scrolling content in `StickyAside.Main` and the panel that should stick in `StickyAside.Aside`. DOM order stays main then aside for screen readers.

```tsx title="steps-with-preview.tsx" preview="StickyAsideDemo"
import { Button, Card, CardContent, Heading, StickyAside, Stack, Text } from "@zedtech/zedkit-ui";

<StickyAside className="[--zk-sticky-top:4.5rem]" side="right">
  <StickyAside.Main>{/* steps */}</StickyAside.Main>
  <StickyAside.Aside asChild>
    <Card>
      <CardContent>
        <Button>Save</Button>
      </CardContent>
    </Card>
  </StickyAside.Aside>
</StickyAside>
```

**Visible result:** on wide viewports the card stays under the header while you scroll the steps; on phones the columns stack (aside after main by default).

### 2. Tune columns and mobile order

Use `ratio="1/3"` or `side="left"` when the sticky column should sit on the other side. Pass `mobile="stack-before"` when the preview should appear above the steps on narrow screens without changing DOM order.

```tsx title="left-summary.tsx" preview="StickyAsideDocStepsDemo"
import { Card, CardContent, StickyAside, Text } from "@zedtech/zedkit-ui";

<StickyAside side="left" from="md" ratio="2/5" scrollable>
  <StickyAside.Main>…</StickyAside.Main>
  <StickyAside.Aside>
    <Card>
      <CardContent>
        <Text variant="muted">Summary</Text>
      </CardContent>
    </Card>
  </StickyAside.Aside>
</StickyAside>
```

## Final result

One section scrolls natively: the aside uses `position: sticky` inside the grid and stops at the section edge. No JavaScript runs in the layout primitive.

## Troubleshooting

**Aside never sticks** — A parent with `overflow: hidden`, `auto`, or `scroll`, or a `transform`, sits between the layout and the viewport. Move `StickyAside` to the normal page flow or remove that ancestor constraint.

**Panel hides under the header** — Set `className="[--zk-sticky-top:7rem]"` (or your header offset) on `StickyAside`.

**Tall summary clipped** — Pass `scrollable` so the aside keeps sticky with an internal scroll area.
