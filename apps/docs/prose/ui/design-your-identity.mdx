## Live editor

Mist is already filled in. Change spacing first, then watch the card. Dark turns the site and the card dark so you edit the dark colour pair. Contrast chips warn when text misses WCAG AA or accent and border miss 3:1 against the background. Describe a look and Suggest; review the list (colour rows include a swatch), then Apply or Discard. When Suggest is off, a keyword match fills the preview instead. Apply to the whole site once; later field changes keep the site in step. The address bar keeps the draft so a refresh or a shared link opens the same look. Reset restores the look you picked. CSS and JSON fields follow the draft; Copy CSS and Copy JSON put them on the clipboard.
