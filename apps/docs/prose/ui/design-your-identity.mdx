## Live editor

Mist is already filled in. Change spacing first, then watch the card. Dark previews the dark colour pair on that card only. Contrast chips warn when text and background miss WCAG AA. Describe a look and Suggest; review the list, then Apply or Discard. When Suggest is off, a keyword match fills the preview instead. The address bar keeps the draft so a refresh or a shared link opens the same look. Reset restores the look you picked. CSS and JSON fields follow the draft; Copy CSS and Copy JSON put them on the clipboard.
