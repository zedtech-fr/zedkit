These rules describe how the docs site frame is meant to look. The live site can still use Glass tokens in places; this page is the target look, not a claim that every page already matches.

## Who this is for

Visitors reading the docs, and anyone about to restyle the site frame (header, sidebar, prose, home, preview frames). Kit specimens keep their own look. This page states the frame.
