These rules are the docs chrome contract. The next home pass paints them. Live first paint can still use Glass tokens until that pass; this page is not a claim that home already matches.

## Who this is for

Visitors reading the docs, and anyone about to restyle the site frame (header, sidebar, prose, home, preview frames). Kit specimens keep their own look. This page states the frame.

## Color and surfaces

Page fill is a neutral reading surface. Body text is zinc-neutral. Indigo/violet are not page fill or body text.

Default site chrome actions are black: stock `--primary` (`240 5.9% 10%` in [`packages/ui/src/styles.css`](https://github.com/zedtech-fr/zedkit/blob/main/packages/ui/src/styles.css)). Site chrome actions are not Glass `--primary` unless inside a high-value panel. Glass `--primary` is indigo (`243 70% 46%` in [`packages/ui/src/identities/glass.css`](https://github.com/zedtech-fr/zedkit/blob/main/packages/ui/src/identities/glass.css)).

A high-value panel is a Glass-material site-owned overlay or marketing card (Guides menu panel, glass header chips, raised marketing code wells). It is not the page, not body copy, and not default header or hero CTAs.

Violet/glass are panel and chip accents (Glass `--accent` / glass material), not reading color.

## Type

One docs title per page. Prose is 15px. Body copy is 14px. Dense UI (controls, tabs, nav) has a 13px floor: nothing a person must read to act goes below that. Phone targets are 44px.

Token names and the owner table stay in [VISUAL-CONTRACT.md](https://github.com/zedtech-fr/zedkit/blob/main/apps/docs/VISUAL-CONTRACT.md).

## Buttons: site vs kit

Site chrome buttons are the docs shell's actions (header, hero, footer, guide nav). They follow the chrome rules above: near-black by default, not Glass indigo, unless they sit inside a high-value panel.

Kit [`Button`](/docs/ui/trigger-actions-with-buttons) is for specimens and apps. Its default variant follows the specimen identity, including Glass indigo. Copy that pattern into your app; do not copy it onto this site's frame.

## Chips, cards, and rhythm

Chips are compact status or selection controls (pills). They may take violet/glass as an accent.

Cards: site-owned glass cards may take sheen. Specimen grids stay flat.

Rhythm: 4px base. Gaps between groups are 32–48px. Marketing bands are 64–96px. Numbers live in [VISUAL-CONTRACT.md](https://github.com/zedtech-fr/zedkit/blob/main/apps/docs/VISUAL-CONTRACT.md); this page restates the visitor meaning.

## Motion

Chrome uses named motions only (`reveal`, `settle`, `emphasis`, `glide`, `feedback` in [signature.md](https://github.com/zedtech-fr/zedkit/blob/main/docs/design/signature.md)). It does not invent durations. `prefers-reduced-motion` removes displacement.
