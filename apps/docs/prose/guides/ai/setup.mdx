## Who this is for

You use a **coding agent** (Cursor, Muse, Claude Code, Codex, or similar) on a git repo (empty or already with team rules) and want one paste to hand the agent — no back-and-forth on how to start.

## What the agent will do

1. Add `@zedtech/zedkit-ai` if missing (`pnpm add -D -w` at a pnpm workspace root when `pnpm-workspace.yaml` exists).
2. Run `npx @zedtech/zedkit-ai setup --provider cursor` (**`setup` preset by default**, adopt mode — keeps your files on collision; override with `--preset starter|setup|core|full` if needed). Use `--provider muse`, `claude`, `codex`, comma-separated names, or `all` to match your tool.
3. Run **`/setup-ai`** — phases A–E (audit, **batched discovery interview** — answer or delegate, do not skip — build `product.md`, domain rules, personas, `design.md` when relevant, repo skills, score and learn), then verify and report.
4. Run `npx @zedtech/zedkit-ai validate` until stdout is `ok`.

**Time:** about 15–45 minutes for a typical app repo once the agent starts (see the setup-ai skill intro).

## Single-repo vs workspace

| Situation | Where to paste the prompt |
| --- | --- |
| One git repository | That repo's root |
| Workspace with several checkouts | The workspace root first; `/setup-ai` runs workspace mode and proposes per-repo setup inside each child |

## Manual path (same result)

```sh
pnpm add -D @zedtech/zedkit-ai   # workspace root: pnpm add -D -w @zedtech/zedkit-ai
npx @zedtech/zedkit-ai setup --provider cursor
```

Then **`/setup-ai`** in your agent, then:

```sh
npx @zedtech/zedkit-ai validate
```

## Already on 0.12?

Re-run `npx @zedtech/zedkit-ai setup` (adopt keeps your files; kit copies
land as `*.kit.md` / `zk-<name>`), then `/setup-ai`. Opt-in
`npx @zedtech/zedkit-ai validate --setup` checks plan coverage, gate-log shape, and that the
setup went deep: `/setup-ai` reads the code first with read-only subagents
(`npx @zedtech/zedkit-ai scan` sizes them), writes domain rules and nested `AGENTS.md`
files from what they found, fills `.agents/tokenomics.md` (cheap models on
`check`/`build` at `trivial`/`standard`, the strong model on `sensitive`/`critical`),
and runs `zedkit-ai sync`.
Full notes: the package README `Upgrading from 0.12` section.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| `validate` not `ok` | Run from repo root; fix each `path: message` line or re-run `setup` after resolving collisions. |
| Agent skips `/setup-ai` | Paste the prompt again; mechanical install alone is not done. |
| Unknown provider | Use `cursor`, `claude`, `codex`, `muse`, `all`, or comma-separated names only. |
