## Who this is for

You ship a public Next.js site and want sitemap, robots, page metadata, and one JSON-LD graph per page without hand-writing spec strings.

## Prerequisites

- Node.js 22+
- Next.js App Router project
- `pnpm add @zedtech/zedkit-seo`

## Wire the site

### 1. Describe the site once

```ts
import type { SiteMetadata } from "@zedtech/zedkit-seo";

export const site: SiteMetadata = {
  name: "Example",
  url: "https://example.com",
  defaultLocale: "en",
  locales: ["en"],
};
```

### 2. `app/robots.ts`

```ts
import type { MetadataRoute } from "next";
import { buildRobots } from "@zedtech/zedkit-seo";

import { site } from "@/lib/site";

export const dynamic = "force-static";

export default function robots(): MetadataRoute.Robots {
  return buildRobots({ siteUrl: site.url });
}
```

### 3. `app/sitemap.ts`

```ts
import type { MetadataRoute } from "next";
import { buildSitemapEntries } from "@zedtech/zedkit-seo";

import { site } from "@/lib/site";

export const dynamic = "force-static";

export default function sitemap(): MetadataRoute.Sitemap {
  return buildSitemapEntries({
    siteUrl: site.url,
    locales: site.locales,
    localeInPath: false,
    pages: [{ path: "" }, { path: "/about" }],
  });
}
```

### 4. Page metadata (`generateMetadata`)

```ts
import { buildPageMetadata } from "@zedtech/zedkit-seo";

import { site } from "@/lib/site";

export function generateMetadata() {
  return buildPageMetadata({
    site,
    page: { title: "About", description: "About this example site." },
    locale: "en",
    pathname: "/about",
    localeInPath: false,
    openGraphLocale: "en_US",
  });
}
```

### 5. JSON-LD on the page

```tsx no-preview="JSON-LD data rendered into a script tag, nothing visible"
import { buildWebPageJsonLd } from "@zedtech/zedkit-seo";

const jsonLd = buildWebPageJsonLd({
  title: "About",
  description: "About this example site.",
  url: "https://example.com/about",
});

export default function About() {
  return (
    <>
      <script type="application/ld+json" dangerouslySetInnerHTML={{ __html: JSON.stringify(jsonLd) }} />
      <main>...</main>
    </>
  );
}
```

With `output: "export"`, keep `export const dynamic = "force-static"` on every metadata route (see the zedkit docs site).

## Verify

- `pnpm build`, then open `/robots.txt` and `/sitemap.xml` on your preview host.
- View source on `/about`: one canonical, Open Graph tags, and one `application/ld+json` script.
- This repo runs `node apps/docs/scripts/verify-seo-tutorial.mjs` in `docs:check`.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| Build fails on `/robots.txt` with static export | Add `export const dynamic = "force-static"` to `robots.ts`, `sitemap.ts`, and other route handlers. |
| Duplicate JSON-LD graphs | Emit one script per page; nest breadcrumbs via `buildWebPageJsonLd({ breadcrumb })`. |
| Wrong canonical on locale-prefixed sites | Pass `localeInPath: true` and paths that include the locale segment. |
