## Who this is for

You build internal admin tools in React and want one screen that combines layout, data table, side-panel editing, and destructive confirmation — using the same components as the live docs demos.

## Prerequisites

- Node.js 22+, a Next.js App Router app, React 19, Tailwind CSS v4.
- Theme wired first: follow [Theme an admin app](/docs/ui/theme-an-admin-app-dark-light-included) (`.dark` class + kit globals).
- Keyboard: tab through the table actions; the drawer traps focus until closed.

## Troubleshooting

**Unstyled controls** — Kit CSS and Tailwind `@source` for `@zedtech/zedkit-ui` are missing. Re-run the theme guide; the table and buttons should use design tokens, not browser defaults.

**Hydration warnings** — Keep `"use client"` on the dashboard module (drawer and dialog use client state). The route file can stay a server component that imports the client view.

**Focus lost after closing the drawer** — Use `DrawerClose` (as in the snippet) so focus returns to the trigger; avoid unmounting the drawer with a bare conditional that skips the close animation.
