## Who this is for

You found zedkit, you like how it looks, and you do not write code — or not
today. This page is your door. It splits the work honestly: the design part
is yours and needs no terminal; the app part still needs someone technical
(a developer, or a coding agent you supervise). zedkit is a component kit,
not a website builder, and there is no one-click hosting behind this page.

## The three steps

### 1. Design the look (you, in the browser)

Open [Design your identity](/docs/ui/design-your-identity). Pick a starting
look, then tune colour, radius, spacing and type on a live card. Flip the
dark preview to check both themes; contrast warnings tell you when a pair
fails. When it reads right, use **Copy CSS** (or **Copy JSON**) — and keep
the page address: it carries your design, so the link reopens the exact
same draft.

**Your time:** about 15–30 minutes of taste. No account, no install.

### 2. Hand it over (a coding agent or a developer)

Send the editor link (or the copied tokens). Creating the app, installing
`@zedtech/zedkit-ui`, wiring the theme, pasting your tokens in and deploying
is their work — [Getting started](/docs/getting-started) covers that install
path. If they work through a coding agent, also send
[Set up your coding agents](/docs/set-up-your-coding-agents): it installs the
optional AI kit into the repo, nothing more. This step happens in a
repository and a terminal; you supervise and review, you do not type the
commands.

**Their time:** roughly 1–2 hours the first time, minutes for later
changes.

### 3. Review and iterate (you, in the browser)

Open the deployed preview they send back. Wrong blue? Radius too round?
Adjust in the editor, copy the new tokens, send them over. Each round is
the same loop: your eyes, their paste.

## What zedkit is not

- Not a no-code website builder: pages are real React components in a real
  app, assembled by your agent or developer.
- Not hosting: the app deploys wherever your technical side puts it
  (Vercel and friends are the usual answers).
- Not a template store: there is no one-click starter today — the agent
  setup page is the on-ramp instead.
