# Security policy

## Supported versions

Published `@zedtech/zedkit-*` packages on npm follow semver; security fixes
land on the latest release line for each major. The `main` branch is also
supported for contributors cloning the monorepo.

## Reporting a vulnerability

Use [GitHub private vulnerability
reporting](https://github.com/zedtech-fr/zedkit/security/advisories/new)
— do not open a public issue for a suspected vulnerability. Include a
minimal reproduction and the commit or package version you tested against.
Expect an acknowledgement within a few days; fixes ship as small PRs on
`main` and patch releases on npm when a published package is affected.
