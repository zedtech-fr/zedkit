# Security policy

## Supported versions

Only the latest `main` is supported; the packages are pre-1.0 and not
on npm yet.

## Reporting a vulnerability

Use [GitHub private vulnerability
reporting](https://github.com/zedtech-fr/zedkit/security/advisories/new)
— do not open a public issue for a suspected vulnerability. Include a
minimal reproduction and the commit you tested against. Expect an
acknowledgement within a few days; fixes ship as small PRs on `main`.
