# Security policy

## Supported versions

Published `@zedtech/zedkit-*` packages on npm: the latest release on the
`main` branch. Pre-1.0 minors may include breaking changes; see package
changelogs and `docs/migrations/` when upgrading.

## Reporting a vulnerability

Use [GitHub private vulnerability
reporting](https://github.com/zedtech-fr/zedkit/security/advisories/new)
— do not open a public issue for a suspected vulnerability. Include a
minimal reproduction, affected package and version, and the commit you
tested against. Expect an acknowledgement within a few days; fixes ship
as small PRs on `main`.
